# How I Solve Problems

When facing a technical issue, I usually follow this process:

1. Understand the problem.
2. Gather relevant information.
3. Reproduce the issue whenever possible.
4. Review logs and available evidence.
5. Analyze data using SQL or system tools.
6. Identify the root cause.
7. Implement or recommend a solution.
8. Document the findings.
9. Look for ways to prevent the issue from happening again.
